# ECU Copilot：实际工作使用与数据可信度说明

## 1. 这套软件解决什么

不是“输入一个工况就自动给标准答案”，而是把硬件工程问题整理成：问题定义 → 事实 → 物理因果 → 候选方案 → 验证 → 决策 → 回归 → EDR。

## 2. 典型实际问题

- EMC：RE/CE 超标、BCI 抗扰度异常、ESD 后复位、线束共模电流异常。
- 功率：负载突变、启动/关断过冲、欠压、纹波、保护阈值。
- BLDC：急停泵升、米勒直通、死区、堵转热应力、换相异常。
- WCCA：采样精度、温漂、器件公差、相关性、RSS/Monte Carlo、EOL Calibration。
- 替代料：Spec-to-Spec、SOA、Qg/Qgd、Rds(on)、热阻、EMC、AEC/PPAP/PCN。
- SI：CAN-FD/SerDes 反射、串扰、地弹、时序裕量。
- 量产：Cpk/Ppk、EOL 误判、批次漂移、Control Plan。
- 安全可靠性：故障注入、诊断覆盖率、FTTI、安全状态、寿命。

## 3. 什么来自规则，什么来自输入

### 固定/内置

公式、物理关系、风险评分骨架、验证方法类别、工程门禁结构、标准条款库属于“专家知识”。这些不是当前项目的实测。

### 当前工况输入

项目名称、阶段、ASIL、客户节点、Spec、实际测量、测试条件、环境、失效现象、工程约束、结构化测量值等来自当前工程。

### 计算结果

例如误差预算、热裕量、风险分数、VOI 排序、方案总分，是根据规则 + 当前输入计算出的结果；没有真实输入时只能是模型结果。

### 基准样例

系统预置的 EMC/WCCA/BLDC 等样例中的数字属于演示数据，UI 会标记为 `BENCHMARK`。工程师实际使用时应覆盖为 `USER_MEASURED` 或通过文件导入标记为 `IMPORTED`。

## 4. EMC 建议最小输入集

对于 RE/CE：频点、Peak/AVG/QP、Limit、带宽、线束长度、供电、电流、PWM/DC-DC 频率、壳体/屏蔽状态。

对于 BCI：注入电流、频率、注入方式/探头、线束长度、ECU 功能状态、受扰节点波形、采样误差、CAN 错误帧、恢复时间。

建议把“注入电流 Iinj → 敏感节点噪声/误差 → 功能状态 → 恢复时间”做成同一条记录。

## 5. WCCA 建议最小输入集

至少把：名义值、初始公差、温漂、老化、负载变化、样本数、实测分布、目标规格边界分开输入。

EOL Calibration 只能关闭可观测、可重复校准的初始误差；温漂、老化、相关性和未建模误差仍需要证据。

## 6. 最终使用原则

1. 软件可以帮助工程师缩小搜索空间，但不能把计算值冒充实测。
2. 标准条款必须由项目人员核对适用版本和客户约定。
3. 对安全、绝对额定值、法规/客户门限，不以 AI/规则的单次输出代替实测或正式签核。
4. 最关键的未知量优先进入 VOI 验证。
