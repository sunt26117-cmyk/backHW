# WP6c-2 · 8 个核心事实面 Ownership

正式结构是 **7 个主工作台 + 1 个横切 Trace 审计面**。

| 事实面 | 唯一主责 |
|---|---|
| 总览 / First Screen | 当前决策快照、下一步与反转条件 |
| 工程事实 | IssueInput、测量来源、缺参、证据分类 |
| 物理分析 | 确定性机理、Pattern、公式与计算输出 |
| 方案决策 | CandidateAction、VETO、CTSQL、最终决策框架 |
| 验证与回归 | 试验计划、VOI、回填闭环、系统回归 |
| 功能安全 / 可靠性 | 安全目标、诊断链、供应链/可靠性专项 |
| 决策交付 | RACI、EDR/ECR、偏差与客户交付物 |
| Trace 审计 | provenance 与输入→计算→结论追溯（横切，不拥有新的业务事实） |

其它页面只能展示摘要、当前状态或跳转，不再复制另一页的完整解释。
